# Vendored game-dev guides

From https://github.com/gamedev-skills/awesome-gamedev-agent-skills (Apache-2.0, see
`vendor/LICENSE` and `vendor/NOTICE`). Each original `SKILL.md` was renamed `GUIDE.md` so it
is read as a reference, not loaded as a separate skill. Content is unchanged.

| Guide | Use for casino games |
|---|---|
| `game-feel` | Anticipation on late reels, win tiers, counters, easing, screen shake on big wins |
| `game-ui-ux` | HUD layout, bet selector, modals (autoplay/bonus-buy confirmation), responsive |
| `audio-design` | Reel stops, win stings, music ducking, mute toggle |
| `performance-optimization` | Profiling, frame budget on mobile |
| `shader-programming` | Glows, dissolves, symbol highlight shaders |
| `create-game-assets` | Asset pipeline, atlases, placeholder art |
| `pixijs-rendering` | 2D PixiJS renderer (Web SDK default) |
| `threejs-scene-setup`, `threejs-gltf-loading`, `threejs-materials-lighting` | Extra Three.js notes |
| `prototype-fast` | Fast visual prototype with mock books |

Ignore any advice in these guides that conflicts with Stake Engine rules (e.g. loading from a
CDN, persistent progression, gameplay-affecting physics) – the Stake rules win.
